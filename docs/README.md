# Сайт учёта ТМЦ

Две страницы:

- `zayavka.html` — форма заявки для сотрудников (вместо Google Формы). Ссылка на офис: `zayavka.html?office=almaty`.
- `index.html` — рабочее место ответственных: сводка, заявки, склад, выдано, мебель по местам, журнал, загрузка из файла с ИИ.

Данные хранятся в Google Таблице офиса. Сайт обращается к ней через скрипт таблицы (файл `Api.gs`).

## Новый офис

1. Скопируйте таблицу офиса (скрипт скопируется вместе с ней), запустите «1. Первичная настройка».
2. Задайте пароль: меню → Настройки → «Пароль сайта ТМЦ».
3. Разверните скрипт: «Развёртывание → Новое развёртывание → Веб-приложение», запуск от вашего имени, доступ «Все». Скопируйте ссылку `/exec`.
4. Добавьте офис в `offices.js`.

## Обновление кода скрипта

После любой правки `.gs`-файлов: «Развёртывание → Управление развёртываниями → ✏️ → Версия: новая версия → Развернуть». Ссылка не меняется.
